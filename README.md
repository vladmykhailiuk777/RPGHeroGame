Підземелля Долі

Про гру
Підземелля Долі — це текстова RPG-гра у жанрі dungeon crawler, написана на чистому C++ без сторонніх бібліотек.
Гравець досліджує процедурно згенеровані рівні підземелля, б'ється з ворогами, підбирає предмети та намагається вижити якомога довше.

Гра побудована навколо трьох класичних механік:
- Дослідження — карта вкрита туманом війни, який розкривається по мірі руху
- Бій — покрокова система з атакою, інвентарем і втечею
- Прогресія — гравець отримує рівні, нові характеристики та предмети


Ціль гри
Пройти якомога більше рівнів підземелля, не загинувши.

На кожному рівні потрібно знайти вихід `X`, уникаючи або перемагаючи ворогів на своєму шляху.
Чим далі ви просуваєтесь — тим сильніші вороги зустрічаються на шляху.

Що є на карті
| Символ | Що означає |
|--------|------------|
| `@` | Ваш герой |
| `E` | Ворог |
| `$` | Золото (+50) |
| `^` | Пастка (-20 HP) |
| `I` | Предмет для підбору |
| `X` | Вихід на наступний рівень |
| `#` | Стіна |
| `?` | Туман війни (ще не досліджено) |



Керування
| Клавіша | Дія |
|---------|-----|
| `W` | Рух вгору |
| `A` | Рух вліво |
| `S` | Рух вниз |
| `D` | Рух вправо |
| `I` | Відкрити інвентар |
| `Q` | Вийти з гри |
Після кожної клавіші потрібно натиснути Enter.



Система бою
Коли гравець наступає на клітинку з ворогом `E` — починається покроковий бій.

У бою доступні три дії:
1. Атака — завдати шкоди ворогу. Шкода розраховується як `атака - захист ворога + випадковість`
2. Інвентар — використати предмет прямо під час бою
3. Втеча — спроба втекти залежить від показника удачі героя

Після перемоги: `+40 XP` і `+20 золота`.



Предмети та інвентар
Підбирати предмети можна наступаючи на клітинку `I`.
Інвентар вміщує до 6 предметів одночасно.

| Предмет | Ефект |
|---------|-------|
| Зілля лікування | Відновлює 40 HP |
| Отрута ельфів | Відновлює 70 HP |
| Камінь сили | Атака +8 (назавжди) |
| Щит воїна | Захист +6 (назавжди) |

Використати предмет можна через меню інвентаря (`I`) — як на карті, так і під час бою.

Прогресія персонажа
За кожного вбитого ворога гравець отримує 40 XP.
При накопиченні 100 XP відбувається підвищення рівня:

- `HP +20` (і повне відновлення)
- `Атака +5`
- `Захист +2`

Вороги стають сильнішими разом із рівнем підземелля:

| Рівень | Ворог | HP | Атака |
|--------|-------|----|-------|
| 1 | Скелет | 45 | 12 |
| 2 | Орк | 80 | 18 |
| 3+ | Темний Лицар | 150 | 28 |
